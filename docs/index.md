# 🌟 Bienvenido a LumiDOC

Documentación del **Sistema Luminova** - Dashboard de Monitoreo Energético Multi-tenant

## 📖 Sobre el Proyecto

Sistema web completo de monitoreo eléctrico trifásico con:
- Autenticación JWT
- Visualización en tiempo real
- Gestión de clientes/empalmes
- Persistencia en MongoDB Atlas

## 🚀 Stack Tecnológico

**Backend**: Node.js, Express, MongoDB, Socket.io  
**Frontend**: React 18, TypeScript, TailwindCSS, Recharts
